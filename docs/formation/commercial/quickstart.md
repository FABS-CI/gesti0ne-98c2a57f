# Quick Start — Commercial
1. **Client** : `/clients/nouveau`.
2. **Proforma** : `/proformas/nouveau` → Envoyer → Convertir.
3. **Commande** : `/commandes/:id` → Valider.
4. **Colisage** : `/colisage/:id` → Prêt.
5. **Livraison** : `/livraisons/nouveau` → Assigner → BL → Valider retour.
6. **Retour** : `/retours/nouveau`.
