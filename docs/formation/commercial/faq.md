# FAQ — Commercial
**Q. Doublon client détecté** → utiliser la fiche existante, jamais recréer.
**Q. Stock insuffisant pour valider commande** → alerter le gestionnaire de stock, proposer partiel au client.
**Q. Client réclame un BL** → réimprimer depuis `/livraisons/:id`.
**Q. Comment annuler une commande ?** → seul le responsable commercial ; sinon créer un avoir après facturation.
