# Erreurs fréquentes — Commercial
| Cas | Cause | Correction |
|---|---|---|
| Doublon client | Recherche non faite | Fusionner via Super Admin |
| Commande bloquée | Stock insuffisant | Attendre réception ou livraison partielle |
| Livraison sans preuve | Oubli signature | Rappeler livreur, régulariser sous 24h |
| Facture non émise | Comptabilité en retard | Escalader au responsable comptable |
