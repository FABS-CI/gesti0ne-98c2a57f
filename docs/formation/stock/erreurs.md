# Erreurs fréquentes — Stock
| Cas | Cause | Correction |
|---|---|---|
| Stock négatif | Sortie sans stock disponible | Bloqué : effectuer une entrée ou un transfert |
| Transfert "en transit" | Non réceptionné | Réceptionner côté destination |
| Écart inventaire non expliqué | Casse/vol non déclaré | Ajustement avec motif |
| Réception impossible | Achat non validé | Valider le bon d'achat d'abord |
