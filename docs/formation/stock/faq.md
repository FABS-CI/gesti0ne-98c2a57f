# FAQ — Stock
**Q. Une ligne d'inventaire a un écart énorme** → recompter avant validation, sinon signaler.
**Q. Un transfert reste "expédié"** → aller sur le dépôt destination et le réceptionner.
**Q. Où voir qui a fait un ajustement ?** → historique du mouvement, colonne "utilisateur".
**Q. Puis-je modifier un mouvement ?** → Non ; créer un mouvement inverse avec motif.
