# Quick Start — Stock
1. **Réception** : `/achats/:id` → Réceptionner → quantités reçues → Valider.
2. **Transfert** : `/transferts/nouveau` → source/destination → Expédier → Réceptionner.
3. **Inventaire** : `/inventaires/nouveau` → compter → saisir → Valider.
4. **Ajustement** : `/stock/ajustements/nouveau` → motif obligatoire.
5. **Rapports** : `/rapports/stock`.
