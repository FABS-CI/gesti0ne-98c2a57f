# FAQ — Comptabilité
**Q. Le paiement est refusé "dépasse le solde restant"** → réduire le montant, ou répartir sur plusieurs factures.
**Q. Impossible de valider une facture** → exercice clôturé ou client sans compte ; vérifier `/exercices`.
**Q. Le KPI encaissé n'a pas bougé** → paiement en statut `annule` ou non validé ; rafraîchir la page.
**Q. Comment retrouver qui a annulé un paiement ?** → `/admin/audit-paiements` (raison + notes + auteur + date).
**Q. Puis-je supprimer une facture ?** → Non ; créer un avoir.
