# Erreurs fréquentes — Comptabilité
| Code / message | Cause | Correction |
|---|---|---|
| "Le montant dépasse le solde restant" | Sur-paiement | Réduire ou répartir sur plusieurs factures |
| "Référence obligatoire" | Champ vide | Saisir n° chèque / transaction / reçu |
| "Raison d'annulation obligatoire" | Annulation sans motif | Saisir la raison factuelle |
| "Permission refusée" | Rôle ≠ admin/DG/comptable | Escalader au Super Admin |
| "Écriture sur exercice clôturé" | Exercice fermé | Utiliser un exercice ouvert |
| Statut incohérent | Anomalie données | Signaler au support ; ne pas corriger en direct |
