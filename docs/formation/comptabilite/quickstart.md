# Quick Start — Comptabilité
1. **Nouvelle facture** : `/factures/nouvelle` → client → commande → Valider.
2. **Nouveau paiement** : `/paiements/nouveau` → client → facture(s) → montant + référence → Valider.
3. **Annulation** : ouvrir le paiement → Annuler → raison → Confirmer.
4. **Historique client** : `/clients/:id` onglet Paiements.
5. **Audit** : `/admin/audit-paiements`.
6. **Comparatif** : `/exercices/comparatif` → Exporter PDF.
